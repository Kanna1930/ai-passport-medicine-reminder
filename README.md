# AI Passport — 中文服药提醒 v2

这是一个为 **FoloToy AI Passport (ESP32-C3)** 开发的离线服药提醒应用。网络只用于自动校准时间，完成校时后 Wi-Fi 与蓝牙会主动关闭。

> 本应用只负责提醒，不判断药物、剂量、禁忌或医疗方案。提醒时间应按医生、药师或药品说明中已经确定的用药安排设置。

## v2 主要功能

- **联网只做一件事：校准时间**
  - 首次使用通过官方 BLUFI 方式配网
  - 微信小程序准确名称：**蓝牙配网-FoloToy AI PASSPORT**
  - 蓝牙设备名：`BLUFI_FoloPassport`
  - 支持保存 Wi-Fi 凭据，后续开机自动连接并通过 SNTP 校时
  - 校时完成后自动关闭 Wi-Fi 和 BLE，不保持后台联网
- **全中文、简化操作的页面**
  - 主界面只显示当前时间、提醒时间和今日服药状态
  - 长按 `OK` 修改提醒时间
  - 长按 `UP` 重新联网校时
  - 长按 `DOWN` 清除旧网络并重新配网
  - 到点提醒：`OK` 已服药、`UP` 延后 10 分钟、`DOWN` 今日跳过
- **省电待机**
  - 启动并校时后保留约 30 秒设置窗口，随后自动息屏待机
  - 提醒确认后约 5 秒自动息屏待机
  - 待机前关闭背光、让 ES8311 音频进入休眠，并使用 ESP32-C3 light sleep
  - 通过 RTC 定时器在下一次提醒（或延后 10 分钟）时唤醒
  - Wi-Fi/BLE 在待机期间保持关闭

## 为什么采用这种待机方式

官方当前硬件契约确认了 RTC 定时唤醒，但没有确认三键可以可靠作为低功耗唤醒源。因此本版优先保证“下一次提醒能准时把设备唤醒”，而不是猜测实体键可以从 light sleep 唤醒。

设备进入长待机后，如需提前修改设置，最可靠的方法是重启设备；启动后会重新联网校时，并留出约 30 秒操作窗口。

## 时间与时区

当前版本默认使用 **UTC+8（中国标准时间）**。如果以后需要在其他时区长期使用，可以再增加时区设置页。

## 构建与验证

本仓库固定基于官方 `FoloToy/ai-passport` 提交：

```text
1051209d807fb26f943236b7e02281f13d39bc90
```

GitHub Actions 使用 **ESP-IDF 5.5.3**，执行：

1. 纯提醒逻辑主机测试；
2. 官方 `./tools/validate.sh --static`；
3. 官方 `./tools/validate.sh --firmware`；
4. 生成可从 `0x0` 刷写的 `FoloToy-AI-Passport-full.bin`。

本地如果已经激活 ESP-IDF 5.5.3：

```bash
./scripts/build.sh
```

## 实机仍需验证

固件编译成功并不等于真机验收完成。需要在实际 AI Passport 上检查：中文是否完整显示、首次 BLUFI 配网、错误密码与无网情况、SNTP 校时、网络关闭、提示音、三键操作、light sleep 唤醒，以及真实电池从满电到日常使用一整天的续航。
